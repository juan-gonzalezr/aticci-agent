# ATICCI Agent

Repositorio operativo para Pi Agent, MCPs, políticas de seguridad y automatizaciones internas de ATICCI.

## Objetivo

Centralizar la capa de agente inteligente de ATICCI sin mezclarla con el backend/frontend del e-commerce.

## Componentes previstos

- Pi Agent
- MCP Plane
- MCP Outline
- MCP Server Ops
- MCP Catalog
- MCP Orders
- Políticas de permisos
- Scripts operativos seguros
